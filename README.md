# 스마트 보행 안전 프로그램 (YOLO_project)

교차로 우회전 시 운전자의 시야 사각지대로 인해 발생하는 보행자 사고를 예방하기 위해, **YOLOv11**과 **OpenCV**를 활용하여 실시간 카메라 영상에서 횡단보도(ROI) 내 보행자를 감지·추적하고 운전자에게 직관적인 경고 UI를 제공하는 스마트 보행 안전 시스템입니다.


## 주요 기능 (Key Features)
1. **실시간 카메라 연동**: USB 웹캠으로 도로 영상을 실시간으로 처리
2. **보행자 객체 탐지 및 다중 객체 추적(Tracking)**: YOLOv11n 모델과 다중 객체 추적(ByteTrack) 알고리즘을 결합해 프레임 간 보행자 ID를 일관되게 추적
3. **횡단보도 영역(ROI) 진입 판별**: 보행자의 발끝 좌표(`foot`)를 기준으로 횡단보도 내부 진입 여부 및 주변 접근 여부를 실시간 판별
4. **운전자 경고 전광판 UI 시각화**: 보행자 위치 및 신호등 상태(녹색·적색·미확인)에 따라 `경고` / `주의` / `확인 필요` 3단계 상태를 실시간 시각화 패널로 출력

### 단축키,기능 설명
z,횡단보도 관심 영역(ROI) 재지정 (마우스 드래그 후 Enter로 확정)
g,보행자 신호 상태 수동 전환: 녹색 (GREEN)
r,보행자 신호 상태 수동 전환: 적색 (RED)
u,보행자 신호 상태 수동 전환: 알 수 없음 (UNKNOWN)
p,화면 일시 정지 / 재개
q,프로그램 종료
